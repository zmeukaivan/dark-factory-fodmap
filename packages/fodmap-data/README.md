# @dark-factory-fodmap/fodmap-data

Monash University FODMAP database import scripts and dataset.

## Purpose

- Scripts to import FODMAP data from Monash University
- Curated dataset of foods with FODMAP classifications
- Data transformation and validation

## Data Source

Monash University FODMAP database (the authoritative source for FODMAP data).

## Usage

```bash
npm run import
```
